# Wann Currency Bot

Open-source Telegram bot for currency exchange rates and currency conversion.

## Features

- Check exchange rates in real time
- Convert currencies instantly
- Simple Telegram commands
- Easy to use
- Open source

## Commands

/rates usd
/rates eur
/rates idr

/convert 10 usd idr
/convert 100000 idr usd

/help
/about

## Installation

1. Clone repository

```bash
git clone https://github.com/Cathelynnn/wann-currency-bot.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Add your Telegram Bot Token

Edit:

```python
TOKEN = "YOUR_BOT_TOKEN"
```

4. Run the bot

```bash
python bot.py
```

## Requirements

- Python 3.10+
- python-telegram-bot
- requests
